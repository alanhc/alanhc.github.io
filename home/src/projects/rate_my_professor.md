- School-up
  - `NextJS`, `SSG`, `FastAPI`, `Mongodb`, `JWT`, `CI/CD`, `Github Action`, `Progressive Web App`, `Web Crawling`
  - Efficiently crawled course information from MCU-up and the school's course page using asyncio and aiohttp, reducing the crawling time by 83%.
  - Built a course scheduler and course rating system using NextJS, and implemented a REST API with FastAPI and MongoDB.
  - [demo](https://next-school-up.vercel.app/)
- MCU-up
  - `NodeJS`, `MVC`, `CRUD`, `Express`, `Authentication`, `Server-Side Rendering`, `MongoDB`
  - MCU-up is a review site using MVC pattern, NodeJS, and Express from scratch with Authentication, CRUD, and Server-Side Rendering.
  - Led a team of 5 developers and designers to develop the application.
  - The application has been used by over 1,000 students.
